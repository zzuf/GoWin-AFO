## 実装修正

- 上流 parser の generic/SZARRAY 対応を使用。generic argument、型パラメーター番号、array shape/lower bound、custom modifier、FNPTR 内の完全な署名を canonical signature に保持し、stable ID の衝突を防ぐ。まだ ABI 投影できない型・modifier は opaque/non-callable のまま。
- 上流 API の BYREF 表現変更で `T*` を `**T` にしてしまう問題を回帰テストで修正。
- NuGet 更新検出を数値/prerelease/revision の precedence 比較に変更。stable pin を勝手に preview へ切り替えず、降格・空/不正応答・過大応答・不正 URL を拒否。package/version と retrieval URL の一致も検証する。
- 13 個の reviewed runtime-smoke binding を embedded template から再構築。入力 pin、module path、manifest、gofmt、drift、削除状態からの復元を検証する。
- 生成物と coverage を全て stage してから置換し、途中失敗時に rollback。復旧自体に失敗した場合は backup を残す。手書きファイルとの衝突は失敗させる。
- CI の native-command exit code、未追跡生成差分、checkout credential policy、Go toolchain 選択を強化。Dependabot と LF/binary Git attributes を追加。

## 検証範囲

SDK 26100 の x86/x64 C++ oracle は実行して baseline と比較し、不一致 0。94 facts のうち normalized fixture IR に対応する 34 facts、4 unique symbols を検証する。この限定 evidence を 522,071 件の公式 inventory 全体へ水増ししない。ARM64 native probe は clang-cl で cross-compile のみであり、実行検証済みではない。

Windows 386/amd64 の COM・WinRT を含む非破壊 smoke、cgo bridge build、全 package test、Go cross-compile、fuzz/vet/gofmt、二回生成の差分は公開準備ゲートとして実行する。GitHub hosted workflow の成功は実際の初回実行を待つ必要がある。

最終 full-source generation の manifest は `324928e11641165338e1897bc08fdc8507de23049cea359d0359a4b25758ae65`。74 packages / 433 generator outputs（reviewed slice と manifest を含む）で、1 回の計測は 17.87 秒、累積 allocation delta 8,541,628,736 bytes。allocation の累計は peak memory と異なる。測定値は実装・環境依存であり性能保証ではない。
