This is a record of the state at the first push. Since then, the WinRT metadata source has been pinned to an official NuGet with identical bytes, and CI compiler discovery has been corrected. See the [CI fix record](2026-09-23-ci.md) for details.

The complete new NuGet archives were downloaded, their SHA-256 hashes calculated, and the lock updated. Win32's `sdk_license.txt` and App SDK's `license.txt` and `NOTICE.txt` are byte-identical to the previous versions. Changes to the nuspec files, including App SDK's new Search dependency, were also recorded, but independent locks/providers for API-bearing transitive packages remain incomplete. Updating a meta package is not counted as expanded API support.

The project has not automatically migrated to the latest installed SDK. Existing measured ABI evidence targets 26100, so headers/contracts from another SDK require separate validation.

## Implementation fixes

- Use the upstream parser's generic/SZARRAY support. Preserve generic arguments, type-parameter indices, array shapes/lower bounds, custom modifiers, and complete signatures inside FNPTR in canonical signatures to prevent stable-ID collisions. Types/modifiers without an ABI projection remain opaque/non-callable.
- Fix the conversion of `T*` into `**T` caused by a change in the upstream API's BYREF representation, with a regression test.
- Change NuGet update detection to compare numeric/prerelease/revision precedence. Do not silently switch stable pins to previews; reject downgrades, empty/invalid responses, oversized responses, and invalid URLs. Also verify that package/version and retrieval URL agree.
- Reconstruct 13 reviewed runtime-smoke bindings from embedded templates. Verify input pins, module paths, manifests, gofmt, drift, and restoration of deleted artifacts.
- Stage all generated outputs and coverage before replacing them, rolling back on an intermediate failure. Retain backups if recovery itself fails. Reject collisions with handwritten files.
- Strengthen CI native-command exit-code handling, untracked generation-diff checks, checkout credential policy, and Go toolchain selection. Add Dependabot and LF/binary Git attributes.

## Verification scope

The x86/x64 C++ oracle for SDK 26100 was executed and compared with the baseline, with 0 mismatches. Of 94 facts, 34 facts corresponding to the normalized fixture IR verify 4 unique symbols. This limited evidence must not be inflated into verification of the entire 522,071-symbol official inventory. The ARM64 native probe is only cross-compiled with clang-cl; it is not runtime-verified.

Publication-preparation gates include nondestructive Windows 386/amd64 smoke tests covering COM and WinRT, cgo bridge builds, all-package tests, Go cross-compilation, fuzz/vet/gofmt, and two-pass generation-diff checks. Success on GitHub-hosted workflows must await their actual first execution.

The final full-source generation manifest was `324928e11641165338e1897bc08fdc8507de23049cea359d0359a4b25758ae65`. It produced 74 packages / 433 generator outputs, including the reviewed slice and manifests. One measured run took 17.87 seconds with a cumulative allocation delta of 8,541,628,736 bytes. Cumulative allocation is not peak memory. These measurements depend on the implementation and environment and are not performance guarantees.
